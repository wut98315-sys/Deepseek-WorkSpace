## 1. 工艺动作（最重要）

按顺序写机器人要做的动作，一步一行，写到"判断"就写判断条件：

```
示例：
1. 等待 PLC 给 "工件到位" 信号（DI0）
2. 移动到取料点上方 100mm（P1，joint）
3. 直线下降到取料点（P2，linear，速度 200mm/s）
4. 夹爪闭合（DO0=1），等 DI1 反馈 = 1
5. 直线抬起 100mm
6. 移动到放料点上方（P3）
7. ...
```

你的工艺：

```
1.
2.
3.
```
