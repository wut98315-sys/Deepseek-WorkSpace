# FTP 远程文件传输工具(Web UI)

通过浏览器界面连接 **任意 IP 的 FTP 服务器**,把本机的**文件或整个文件夹**上传到指定的远程目标目录。
文件夹上传会**保留内部目录结构**;支持大文件流式传输、失败自动重试、跳过同名文件、自动创建远程目录。

> 浏览器本身无法使用 FTP 协议,所以本工具由一个 **Python 后端(仅用标准库,零第三方依赖)** 在本地做桥接:
> 浏览器 (HTTP) → 本工具后端 (FTP) → 目标服务器 (IP:21)

## 界面预览

| 模块 | 功能 |
|---|---|
| ① 服务器连接 | 填写主机 IP、端口(默认 21)、用户名、密码、远程目标目录;一键测试连接 |
| ② 添加文件/文件夹 | 拖拽文件或文件夹到区域,或点击「选择文件 / 选择文件夹」 |
| ③ 传输队列 | 逐文件进度 + 总体进度条;每个失败文件可单独重试 |
| ④ 运行日志 | 实时查看传输详情 |

## 快速开始

要求:装有 **Python 3.7+** 的电脑(Windows / macOS / Linux 均可)。

```bash
cd ftp-transfer-ui
python server.py
```

启动后会自动打开浏览器访问 `http://127.0.0.1:8765`。使用方法:

1. 填写 FTP 服务器信息(IP / 端口 / 用户名 / 密码)和**远程目标目录**;
2. 点「测试连接」确认可达(可勾选目标目录不存在时自动创建);
3. 把文件或文件夹**拖进页面**,或用按钮选择;
4. 点「🚀 开始传输」,等待队列完成即可。

## 命令行参数

```bash
python server.py                    # 默认 127.0.0.1:8765 并自动打开浏览器
python server.py --port 9000        # 换端口
python server.py --host 0.0.0.0     # 允许局域网内其他设备访问界面(注意:无鉴权,慎用)
python server.py --no-open          # 不自动打开浏览器
```

## 功能说明

- **文件与文件夹上传**:文件夹(含子文件夹)完整保留远程目录层级;
- **大文件**:请求体以 64 KB 分块流式转发给 FTP,不会整体读入后端内存;
- **断线自动重试**:网络中断时丢弃坏会话、前端按文件整体重发(最多 3 次),避免半截文件;
- **跳过同名文件**:关闭「覆盖同名文件」后,远程已存在的文件自动跳过(不覆盖);
- **自动建目录**:开启后,远程目标目录及文件所在子目录不存在时会逐级创建;
- **中文支持**:服务器目录/文件名均按 UTF-8 处理;
- **FTP 会话复用**:同一目标只保持一条 FTP 连接,顺序传输;
- **界面语言**:简体中文;适用于 Chrome / Edge / Firefox(文件夹上传依赖浏览器的目录选择能力,Chrome / Edge 体验最佳)。

## 安全提示

- 界面服务默认只监听 `127.0.0.1`,密码明文经由本机 HTTP 传输,不会离开本机;
- 请勿用 `--host 0.0.0.0` 部署到不可信网络,该界面没有访问鉴权;
- FTP 密码与登录信息若勾选「记住连接设置」会保存在浏览器 localStorage(仅本机)。

## 常见问题

- **测试连接失败 / 连接被拒绝**:确认目标服务器 FTP 服务已开启、端口正确(默认 21)、防火墙放行;
- **登录失败**:确认用户名密码;多数 FTP 服务不开放匿名登录;
- **被动模式**:本工具使用 FTP 被动模式(PASV),如目标在 NAT / 防火墙后需在服务器侧正确配置被动端口;
- **传输到一半网络断了**:工具会自动重试;若最终失败,请重试该文件或整个队列;
- **空的文件夹**:FTP 没有“空文件夹”概念,只会上传文件夹内的文件并重建目录结构,空文件夹不会被创建。
